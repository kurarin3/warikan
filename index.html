Firebase の設定値が入っていません。js/config.js を開いて、 Firebase コンソールで取得した firebaseConfig を貼り付けてください。

Realtime Database のルールには、同梱の database.rules.json を設定してください。

Firebase が表示するスニペットには databaseURL が含まれないことがあります。 Realtime Database の「データ」タブに出ている URL （https://…-default-rtdb.firebaseio.com など）を手で追記してください。
